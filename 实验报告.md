# Campus Event Manager 功能升级实验报告

## 一、实验目的

本实验旨在对「Campus Event Manager」校园活动管理应用进行全面的技术升级，通过引入现代 Android 开发技术栈，提升应用的性能、可靠性和可维护性。具体目标包括：

1. **列表组件升级**：将传统 ListView 替换为 RecyclerView，实现高性能列表渲染
2. **自定义 UI 组件**：开发侧滑菜单组件，增强用户交互体验
3. **后台任务调度**：使用 WorkManager 替代 Service，实现可靠的后台任务调度
4. **数据存储优化**：引入 MMKV 替代 SharedPreferences，提升轻量级数据存储性能
5. **本地数据库实现**：使用 Room ORM 框架管理活动数据，确保数据安全持久化
6. **用户行为埋点**：实现点击事件统计与去重逻辑，完成基础数据采集能力建设

```java
public class ClickStatisticsManager {
    private static final long DEBOUNCE_INTERVAL = 60 * 1000; // 60秒
    
    public void recordClick(String eventId) {
        long currentTime = System.currentTimeMillis();
        ClickRecord record = clickRecordDao.getClickRecord(eventId);
        
        if (record == null) {
            record = new ClickRecord(eventId, currentTime, 1);
            clickRecordDao.insertClickRecord(record);
        } else {
            long timeDiff = currentTime - record.getLastClickTime();
            if (timeDiff >= DEBOUNCE_INTERVAL) {
                record.setClickCount(record.getClickCount() + 1);
                record.setLastClickTime(currentTime);
                clickRecordDao.updateClickRecord(record);
            }
        }
    }
}
```

## 三、实验基本原理

### 3.1 RecyclerView 视图复用原理

RecyclerView 通过 `LayoutManager` 和 `ViewHolder` 模式实现视图复用，避免频繁创建和销毁 View 对象，显著提升列表滚动性能：

1. **ViewHolder 缓存机制**：`onCreateViewHolder` 创建视图，`onBindViewHolder` 绑定数据
2. **回收池策略**：当 Item 滑出屏幕时，其 ViewHolder 被放入回收池，供新 Item 复用
3. **高效布局计算**：LayoutManager 负责测量和布局，支持线性、网格等多种布局方式

### 3.2 侧滑菜单触摸事件机制

自定义侧滑菜单通过重写 `onInterceptTouchEvent` 和 `onTouchEvent` 实现精确的触摸事件处理：

1. **事件拦截判断**：在 `onInterceptTouchEvent` 中检测滑动方向，水平滑动时拦截事件
2. **手势识别**：通过 `VelocityTracker` 检测滑动速度，判断快速滑动意图
3. **边界处理**：滑动过半自动展开菜单，否则回弹关闭

### 3.3 WorkManager 任务调度原理

WorkManager 提供生命周期感知的后台任务调度，确保任务可靠执行：

1. **任务约束条件**：支持网络状态、电池状态、设备空闲等多种约束
2. **任务类型**：`OneTimeWorkRequest`（一次性任务）和 `PeriodicWorkRequest`（周期性任务）
3. **持久化存储**：任务信息持久化到数据库，进程被杀后仍可恢复执行

### 3.4 MMKV 高性能存储原理

MMKV 基于 mmap 内存映射实现高性能键值对存储：

1. **内存映射**：将文件直接映射到进程地址空间，减少数据拷贝
2. **增量更新**：仅写入变更部分，提升写性能
3. **自动加密**：内置 AES-128/256 加密，保障数据安全
4. **多进程支持**：支持多进程并发读写，无需额外同步

### 3.5 Room ORM 框架原理

Room 作为 Google 官方 ORM 框架，提供类型安全的数据访问：

1. **Entity 注解**：定义数据库表结构，支持编译时验证
2. **DAO 接口**：声明数据访问方法，Room 自动生成实现
3. **LiveData 集成**：支持数据观察，实现响应式 UI 更新
4. **迁移支持**：提供 Migration API，支持数据库版本升级

### 3.6 点击去重算法

采用时间窗口去重策略，确保数据准确性：

1. **时间戳对比**：记录每次点击时间戳，计算与上次点击的时间差
2. **阈值判断**：若时间差 >= 60 秒，则计入统计；否则忽略
3. **原子操作**：使用数据库事务保证数据一致性

#### 4.1.2 侧滑菜单触摸事件实现步骤

（1）**创建自定义 SwipeMenuItemLayout 类**，继承自 ViewGroup：

```java
public class SwipeMenuItemLayout extends ViewGroup {
    private View mForegroundView;    // 前景内容视图
    private View mBackgroundView;    // 背景操作视图（置顶/删除按钮）
    private int mMenuWidth;          // 菜单宽度
    private int mLastX, mLastY;      // 上次触摸坐标
    private boolean mIsSwiping;      // 是否正在滑动
    private boolean mSwiped;         // 是否已滑动过
    private int mTouchSlop;          // 滑动阈值
    
    public SwipeMenuItemLayout(Context context, AttributeSet attrs) {
        super(context, attrs);
        mTouchSlop = ViewConfiguration.get(context).getScaledTouchSlop();
    }
}
```

（2）**重写 onMeasure 方法**，测量前景和背景视图：

```java
@Override
protected void onMeasure(int widthMeasureSpec, int heightMeasureSpec) {
    super.onMeasure(widthMeasureSpec, heightMeasureSpec);
    
    int width = MeasureSpec.getSize(widthMeasureSpec);
    int height = MeasureSpec.getSize(heightMeasureSpec);
    
    // 测量前景视图（占满整个宽度）
    if (mForegroundView != null) {
        mForegroundView.measure(MeasureSpec.makeMeasureSpec(width, MeasureSpec.EXACTLY),
                                MeasureSpec.makeMeasureSpec(height, MeasureSpec.EXACTLY));
    }
    
    // 测量背景视图（只占菜单宽度）
    if (mBackgroundView != null) {
        mBackgroundView.measure(MeasureSpec.makeMeasureSpec(mMenuWidth, MeasureSpec.EXACTLY),
                                MeasureSpec.makeMeasureSpec(height, MeasureSpec.EXACTLY));
    }
}
```

（3）**重写 onLayout 方法**，布局前景和背景视图：

```java
@Override
protected void onLayout(boolean changed, int l, int t, int r, int b) {
    int width = r - l;
    int height = b - t;
    
    // 背景视图布局在右侧
    if (mBackgroundView != null) {
        mBackgroundView.layout(width - mMenuWidth, 0, width, height);
    }
    
    // 前景视图覆盖整个区域
    if (mForegroundView != null) {
        mForegroundView.layout(0, 0, width, height);
    }
}
```

（4）**重写 onInterceptTouchEvent 方法**，判断是否拦截触摸事件：

```java
@Override
public boolean onInterceptTouchEvent(MotionEvent ev) {
    int x = (int) ev.getX();
    int y = (int) ev.getY();
    
    switch (ev.getAction()) {
        case MotionEvent.ACTION_DOWN:
            mLastX = x;
            mLastY = y;
            mSwiped = false;
            break;
        case MotionEvent.ACTION_MOVE:
            int dx = Math.abs(x - mLastX);
            int dy = Math.abs(y - mLastY);
            // 判断是否为水平滑动
            if (dx > mTouchSlop && dx > dy) {
                mIsSwiping = true;
                getParent().requestDisallowInterceptTouchEvent(true);
                return true;
            }
            break;
    }
    return super.onInterceptTouchEvent(ev);
}
```

（5）**重写 onTouchEvent 方法**，处理滑动逻辑：

```java
@Override
public boolean onTouchEvent(MotionEvent ev) {
    if (!mIsSwiping) return super.onTouchEvent(ev);
    
    int x = (int) ev.getX();
    
    switch (ev.getAction()) {
        case MotionEvent.ACTION_MOVE:
            int dx = mLastX - x;
            int newScrollX = getScrollX() + dx;
            // 限制滑动范围
            newScrollX = Math.max(0, Math.min(newScrollX, mMenuWidth));
            scrollTo(newScrollX, 0);
            mLastX = x;
            break;
        case MotionEvent.ACTION_UP:
            mIsSwiping = false;
            // 滑动过半自动打开，否则回弹关闭
            if (getScrollX() > mMenuWidth / 2) {
                scrollTo(mMenuWidth, 0);
            } else {
                scrollTo(0, 0);
            }
            break;
    }
    return true;
}
```

#### 4.1.6 点击去重算法实现步骤

（1）**创建 ClickDebounceUtil 工具类**，封装点击去重逻辑：

```java
public class ClickDebounceUtil {
    private static final long DEFAULT_DELAY = 500; // 默认去重间隔 500ms
    private static final Map<Object, Long> lastClickTimeMap = new HashMap<>();
    
    /**
     * 判断是否为重复点击
     * @param target 点击目标对象（如 View、按钮ID等）
     * @return true-重复点击，false-有效点击
     */
    public static boolean isDuplicateClick(Object target) {
        return isDuplicateClick(target, DEFAULT_DELAY);
    }
    
    /**
     * 判断是否为重复点击（自定义间隔）
     * @param target 点击目标对象
     * @param delayMs 去重间隔（毫秒）
     * @return true-重复点击，false-有效点击
     */
    public static boolean isDuplicateClick(Object target, long delayMs) {
        long currentTime = System.currentTimeMillis();
        Long lastClickTime = lastClickTimeMap.get(target);
        
        if (lastClickTime == null || currentTime - lastClickTime >= delayMs) {
            lastClickTimeMap.put(target, currentTime);
            return false; // 不是重复点击
        }
        
        return true; // 是重复点击
    }
    
    /**
     * 清除指定目标的点击记录
     * @param target 点击目标对象
     */
    public static void clearClickRecord(Object target) {
        lastClickTimeMap.remove(target);
    }
    
    /**
     * 清除所有点击记录
     */
    public static void clearAllClickRecords() {
        lastClickTimeMap.clear();
    }
}
```

（3）**使用 RxJava 实现更灵活的点击去重**：

```java
public class RxClickDebounce {
    /**
     * 创建带去重的点击 Observable
     * @param view 目标视图
     * @param delayMs 去重间隔
     * @return Observable<View>
     */
    public static Observable<View> clicks(View view, long delayMs) {
        return Observable.create(emitter -> {
            View.OnClickListener listener = v -> {
                if (!emitter.isDisposed()) {
                    emitter.onNext(v);
                }
            };
            
            ViewClickDebounce.setOnDebouncedClickListener(view, listener, delayMs);
            
            emitter.setCancellable(() -> {
                view.setOnClickListener(null);
            });
        });
    }
    
    /**
     * 创建带防抖的点击 Observable（使用 RxJava throttleFirst）
     * @param view 目标视图
     * @param delayMs 防抖间隔
     * @return Observable<View>
     */
    public static Observable<View> debounceClicks(View view, long delayMs) {
        return Observable.create(emitter -> {
            View.OnClickListener listener = v -> {
                if (!emitter.isDisposed()) {
                    emitter.onNext(v);
                }
            };
            
            view.setOnClickListener(listener);
            
            emitter.setCancellable(() -> {
                view.setOnClickListener(null);
            });
        }).throttleFirst(delayMs, TimeUnit.MILLISECONDS);
    }
}
```

```kotlin
     * 协程版本点击去重
     * @param delayMs 去重间隔

    fun debounceClick(delayMs: Long = 500, action: () -> Unit) {

        job = CoroutineScope(Dispatchers.Main).launch {

            action.invoke()
        }
    }
```
